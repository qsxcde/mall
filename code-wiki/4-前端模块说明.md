# 4 · 前端模块说明

两个独立的 Vue 3 工程，技术栈相同（Vue 3 Composition API + Vite + Pinia + Vue Router + Element Plus + axios），
但代码不共享，各自有独立的 `api/`、`stores/`、`styles/`。

| 工程 | package.json 项目名 | 端口 | 面向角色 |
| --- | --- | --- | --- |
| [frontend/](../frontend) | `geek-digital-mall` | 5173 | 买家（浏览→下单→支付→评价→售后全链路） |
| [frontendMerchant/](../frontendMerchant) | `geek-merchant-center` | 5174 | 商家（商品、订单、售后、资金、营销） |

两端 `vite.config.js` 均配置：`@` 别名指向 `src`、`/api` 代理到 `http://localhost:8080`（可用 `VITE_API_TARGET` 覆盖），浏览器同源无跨域。

## 4.1 买家端 frontend/

### 目录组织

```
src/
├── api/          # 接口层：request.js（axios 封装）+ 按域拆分 + token.js/helpers.js/adapters.js
├── stores/       # Pinia：user / cart / coupon / collection / message / aftersale / persist
├── router/       # 路由（业务页面懒加载分包）+ 登录守卫
├── views/        # 页面（按域分目录）
├── components/   # AppHeader / AppTopbar / AppFooter / ProductCard / CountdownTimer / AuthAside
├── layouts/      # MainLayout / AuthLayout
├── styles/       # base.css / pages.css
├── data/         # constants.js
└── utils/        # format.js / useNarrow.js
```

### 路由与页面（[router/index.js](../frontend/src/router/index.js)）

| 链路 | 页面 |
| --- | --- |
| 浏览 | `HomeView`（首页）、`CategoryView`（分类）、`ProductView`（详情）、`SearchView`（搜索）、`NewProductView`、`SeckillView`（秒杀） |
| 购物车→下单 | `CartView` → `CheckoutView`（确认订单/结算试算）→ `PaymentView`（支付，含倒计时） |
| 订单 | `OrdersView`（订单中心）、`order/OrderDetailView`、`order/LogisticsView`、`order/ReviewView` |
| 售后 | `aftersale/ApplyView`、`aftersale/DetailView` |
| 个人 | `UserCenterView`、`MemberView`、`FavoritesView`、`HistoryView`、`MyReviewsView`、`CouponView`、`PointsMallView`、`MessagesView` |
| 认证/其他 | `LoginView`、`auth/RegisterView`、`auth/ForgotView`、`AboutView`、`HelpView`、`PolicyView` |

路由守卫：需要登录的页面（下单、个人中心等）无令牌时重定向登录页并携带 `redirect` 回跳参数。

### API 层（`src/api/`）

- `request.js`：统一 HTTP 封装（见 [3-关键类与函数说明](./3-关键类与函数说明.md) 3.10）；
- 按域拆分：`auth.js`、`user.js`、`product.js`、`cart.js`、`trade.js`（下单/支付）、`marketing.js`（优惠券/秒杀/积分）、`review.js`、`aftersale.js`、`message.js`、`content.js`；
- `token.js`：令牌存取；`adapters.js` / `helpers.js`：后端 VO → 视图模型适配与通用参数处理。

### Pinia Stores（`src/stores/`）

| Store | 状态 |
| --- | --- |
| `user` | 登录态与资料（`guestInfo` 占位、登录/登出/清会话，配合 `persist.js` 本地持久化） |
| `cart` | 服务端同步购物车：`add / remove / setQty / toggle / clear` |
| `coupon` | 优惠券领取与可用列表 |
| `collection` | 收藏 |
| `message` | 消息中心未读/列表 |
| `aftersale` | 售后单状态 |
| `persist` | 本地持久化读写工具 |

## 4.2 商家端 frontendMerchant/

### 目录组织

```
src/
├── api/          # request.js + auth / catalog（商品）/ trade（订单）/ inventory（分桶）/ growth（营销/财务）
├── stores/       # merchant.js（商家登录态、资料、角标）
├── router/       # 商家路由 + 登录/资料/角标加载守卫
├── views/        # 经营页面
├── components/   # 业务组件 + charts/（BarChart / DonutChart / LineAreaChart / SparkLine）
├── composables/  # useTableQuery / useCountUp / useElementSize
├── layouts/      # MerchantLayout / SideNav / TopBar
├── utils/        # chart.js / dict.js（状态字典）/ format.js
└── styles/       # tokens.css（设计令牌）/ base.css / element.css
```

### 路由与页面（[router/index.js](../frontendMerchant/src/router/index.js)）

| 页面 | 职责 |
| --- | --- |
| `OverviewView` / `AnalyticsView` | 经营概览、数据看板（`StatStrip`、`charts/*`、`CountUp`） |
| `ProductListView` | 商品管理 |
| `InventoryBucketView` | **库存分桶**管理（对接后端 `inventory` 域） |
| `OrderListView` / `ShippingDeskView` | 订单管理、发货中心（`WaybillCard` 运单） |
| `AfterSaleView` | 售后管理（`MerchantAftersaleStatus` 状态字典） |
| `FinanceSettleView` | 财务结算 / 提现 |
| `MarketingView` | 营销中心 |
| `ReviewView` | 评价管理 |
| `LoginView` | 商家登录（`scope=merchant` 令牌） |

### 组件与 hooks

- 通用：`PageHeader`、`BulkBar`（批量操作条）、`EmptyHint`、`StatusTag`、`ProductThumb`、`UserAvatar`、`OrderDetailBlocks`；
- 图表：`charts/BarChart|DonutChart|LineAreaChart|SparkLine`（轻量 SVG，配 `utils/chart.js` 比例计算）；
- composables：`useTableQuery`（列表查询/分页/筛选通用逻辑）、`useCountUp`、`useElementSize`（图表自适应）。

## 4.3 工程化配置

| 项 | 说明 |
| --- | --- |
| npm scripts | `dev` / `build` / `preview` / `lint` / `format` / `test` / `test:coverage`（后两个为 Vitest） |
| ESLint | ESLint 10 flat config（两端统一；测试文件单独启用 vitest globals） |
| Prettier | Prettier 3，**ratchet 模式**：只约束"相对基线有改动的文件"（CI 立刻变绿 + 每次改动自动收敛风格）；脚本入口 `scripts/check-frontend-style.sh` |
| 单元测试 | **Vitest 3 + jsdom**。只测纯逻辑，不引入 E2E：买家端 44 例（适配层 / 格式工具 / 参数清洗 / 图标白名单守卫），商家端 23 例（字典 / 格式工具 / 图标白名单守卫）。CI 在 build 之前先跑 `npm run test` |
| 按需引入 | `unplugin-vue-components` + `unplugin-auto-import`：`<el-*>` 与图标按需打包。命令式 API（`ElMessage` 等）必须用 `ElementPlusResolver({ importStyle: 'css' })`，否则弹窗无样式 |
| 图标白名单 | 图标由 `vite.config.js` 的 `ICON_NAMES` 精确解析（替代全量注册）。**漏登记的图标不报错、只显示空白**，故 `src/icons.test.js` 扫描模板做守卫 |
| 主包体积 | 买家端 index **1269 kB → 374 kB**（gzip 410 → 136 kB）；商家端 **1.09 MB → 301 kB**（gzip 341 → 105 kB） |
| 依赖 | vue 3、vue-router、pinia、element-plus、axios（两工程一致；已升级 vite 7） |
| 格式约定 | 后端 HTTP 恒 200，业务码在 body（`code != 0` 拦截）；401 自动跳登录 |

# 极客数码商城 — 前端功能点分析报告

> 分析对象：`/Users/wangjie/CodeBuddy/demo`（Vue 3 + Vite + Element Plus + Vue Router + Pinia）
> 分析范围：`src/views`（25 个页面）、`src/components`（5 个）、`src/stores`（7 个）、`src/data/shop.js`

---

## 一、项目概况

| 项目 | 说明 |
| --- | --- |
| 技术栈 | Vue 3 `<script setup>` + Vite 6 + Element Plus + Vue Router 4 + Pinia |
| 页面数量 | 主流程 11 页 + 订单 3 页 + 售后 2 页 + 账户/内容 11 页，共约 25 个视图 |
| 数据来源 | **全部**来自 `src/data/shop.js`（纯静态 Mock），**无任何后端接口调用** |
| 状态持久化 | Pinia + `localStorage`（`persist.js`，前缀 `geek-mall:`） |
| 路由保护 | `requiresAuth` 路由 17 条，未登录跳 `/login?redirect=` |

**核心结论**：当前是一个**完整可点击的前端原型**——页面、交互、路由、视觉均已成型，但业务闭环大量依赖静态 Mock 数据。因此「需要实现的功能点」可以分为两类：

- **A 类：已有 UI 但仅"前端演示"（`ElMessage`/本地 ref，不落库、不闭环）** → 需要补真实逻辑
- **B 类：完全缺失或占位（定义了但未联动）** → 需要从零实现

## 三、按模块的功能点清单

### 1. 首页与全局导航
- 品类导航跳转、Banner 轮播、秒杀/领券/新品楼层预览
- 用户欢迎栏（登录态昵称）、会员/订单/登录入口
- 顶级搜索框（回车跳 `/search?q=`，空值兜底 `iPhone`）
- 消息中心未读红点、购物车角标（`itemCount`）
- 侧栏快捷入口、服务保障条、页脚链接
- 秒级倒计时组件 `CountdownTimer`（循环重置、props 变化重置、卸载清理）

> 缺口：热销榜 Tab（综合/销量/价格/好评）**不改变列表**；「猜你喜欢·换一批」仅弹提示。

### 2. 商品浏览与检索
- **分类页**：面包屑、品类单选、子分类切换、品牌多选、价格区间滑块 + 5 档预设、多维排序（价格可升降）、栅格/列表切换、分页（8 条/页）、空状态
- **搜索页**：URL `?q=` 关键词、分类/品牌/价格/服务筛选、结果计数、排序、分页、关键词高亮
- **详情页**：缩略图切换、规格选择（颜色/版本/套餐）、数量 1–99、加入购物车、立即购买、收藏切换、详情/参数/评价 Tabs、评分、看了又看推荐、浏览历史自动写入
- 复用组件 `ProductCard`（高亮分段、规格展示、角标）

> 缺口：**「服务筛选」`filters.services` 已定义但未参与过滤**（CategoryView 与 SearchView 各一处），属占位。

### 3. 营销活动
- **秒杀页**：6 个场次切换、已结束场次拦截、本场倒计时、商品跳详情、「马上抢」加购、「提醒我」、进度/库存展示
- **新品首发**：6 类 Tab 筛选、首发倒计时、主打抢购/预约提醒、上架卡片加购、即将首发列表
- **领券中心**：券类型筛选、领取写 store、重复领取拦截、抢光禁用、进度百分比、「去使用」跳个人中心
- 优惠券状态 `useCouponStore`（领取去重、结算页选中券跨页持久化）

> 缺口：秒杀库存/进度百分比、领券进度递增均为**纯装饰**，无库存扣减与并发控制。

### 4. 购物车与结算
- **购物车**：行勾选 + 选中态回填、数量增减、单行删除（确认框）、全选、删除选中、已选件数、金额汇总、空车禁用结算、商品跳详情
- **结算页**：步骤条、收货地址选择 + 管理入口、商品清单、配送方式 3 选 1、优惠券选择（跨页持久化）、支付方式 4 选 1、金额计算（商品/运费/优惠/应付）、提交订单 + 地址校验

> 缺口：**优惠码仅弹提示不改金额**；**提交订单不生成订单**（`orders` 为静态数据），结算 → 订单中心断链。

### 5. 支付收银
- 订单号生成、金额读 `?amount=`、14:59 支付倒计时（卸载清理）、4 种支付方式选择、二维码展示、余额不足拦截、支付成功结果页、查看订单/返回首页/返回修改

> 缺口：**支付结果不写回订单状态**，订单永远是静态 `pay` 态。

### 6. 订单中心
- 状态概览卡（可点击取消筛选）、状态 Tab 与 URL `?status=` 双向同步、订单号/商品名搜索、按状态差异化操作按钮、商品跳详情、空状态
- 订单详情：状态头、取消/去支付/提醒发货/申请售后/查看物流/确认收货/去评价/再次购买、物流摘要、信息描述 + 进度时间轴
- 物流跟踪：物流信息与轨迹、**复制运单号（真实写剪贴板）**、联系快递、收货信息
- 发表评价：三维评分 + 综合分计算、500 字内容、≤6 图上传、匿名勾选、提交校验

> 缺口：**取消订单/确认收货/提醒发货/再次购买仅弹提示**，不改变订单状态；**评价提交不落库**（无 review store），订单评价状态不流转。

### 7. 售后服务 ✅ 唯一端到端真实闭环
- 申请页：服务类型选择、关联订单选择、原因必选、问题描述/凭证/电话、提交后 `aftersale.create()` 生成记录并持久化
- 详情页：按 id 读取、处理中/已完成状态、关联订单跳转、售后信息 + 处理进度时间轴

> 缺口：详情页「取消申请」不删除/不改变记录状态。

### 8. 账户体系
- **登录/注册**：登录/注册主 Tab、密码/短信登录子 Tab、手机号正则校验、密码强度与一致性校验、提交写 token 持久化、`redirect` 回跳、60s 验证码倒计时、记住我、找回密码入口、第三方登录展示
- **找回密码**：三步步骤条（验证身份 → 设新密码 → 完成）、验证码倒计时、逐步校验
- **个人中心**：5 个 Tab 与 `?tab=` 路由同步、资料编辑（真实持久化）、头像更换、优惠券分 Tab、地址增/删/默认（真实持久化）、6 项账户安全、售后快捷入口、售后记录筛选

> 缺口：**注册不建账号**；**找回密码不重置**；**第三方登录无点击逻辑**；**地址「编辑」未实现**（仅弹提示）；**账户安全 6 项全为演示提示**；**头像更换未实现**；登录无真实鉴权/无后端校验。

### 9. 会员与积分
- 会员中心：等级卡 + 成长值进度、立即升级、积分商城入口、等级体系/权益展示、每日签到、成长任务
- 积分商城：积分展示、商品卡可用性（不足置灰）、兑换（校验库存/积分 → `deductPoints` 真实持久化）、兑换规则

> 缺口：**每日签到积分加在本地 ref，与 `user.info.points` 不一致、不持久化**；**兑换后库存仅改本地副本，刷新还原**；「立即升级」仅提示。

### 10. 收藏 / 足迹 / 消息 / 评价
- 收藏：列表渲染、取消收藏、加购、清空（均持久化）
- 足迹：列表 + 时间、删除单条、清空、加购（均持久化）
- 消息中心：分类 Tab 过滤、未读角标、点击已读 + 跳转、全部标为已读（均持久化）
- 我的评价：列表渲染（含图片/商家回复）、查看订单、商品跳转

> 缺口：**追加评价/删除评价仅弹提示，不改变数据**（无独立评价 store）。

### 11. 内容页与客服
- 关于我们（数据统计）、帮助中心（FAQ 折叠面板）、退换货政策（条款列表）
- 联系在线客服 / 联系快递 / 客服入口

> 缺口：客服按钮全部为 `ElMessage` 提示，无在线客服会话。

## 五、隐式接口需求（若接入后端）
